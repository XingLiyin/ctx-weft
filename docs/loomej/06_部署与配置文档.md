# LoomeJ 部署与配置文档

## 1. 环境要求

| 组件 | 版本要求 | 说明 |
|------|---------|------|
| Java | 21+ | 必须支持 Project Loom 虚拟线程 |
| Maven | 3.9+ | 构建工具 |
| PostgreSQL | 14+ | 主数据库 |
| Python | 3.10+（可选）| 运行远程 skill MCP server |
| Node.js | 18+（可选） | 运行 Node 类 MCP server |

## 2. 项目构建

### 2.1 结构

```
loomej/
├── pom.xml              父 POM（管理依赖版本）
├── loomej-core/         核心引擎模块
│   └── pom.xml
└── loomej-shell/        Spring Boot 宿主模块
    └── pom.xml
```

### 2.2 构建命令

```bash
# 从根目录构建所有模块
mvn clean package -DskipTests

# 仅构建 shell（含依赖）
cd loomej-shell
mvn clean package -DskipTests

# 生成 fat jar
# 输出：loomej-shell/target/loomej-shell-*.jar
```

### 2.3 关键依赖版本（pom.xml）

```xml
<properties>
    <java.version>21</java.version>
    <spring-boot.version>3.3.x</spring-boot.version>
    <spring-ai.version>1.0.0-M6</spring-ai.version>  <!-- MCP 客户端 -->
    <mybatis-spring-boot.version>3.0.x</mybatis-spring-boot.version>
    <flyway.version>10.x</flyway.version>
    <jackson.version>2.17.x</jackson.version>
</properties>
```

## 3. 数据库初始化

### 3.1 创建数据库

```sql
CREATE USER loome WITH PASSWORD 'loome';
CREATE DATABASE loome OWNER loome;
GRANT ALL PRIVILEGES ON DATABASE loome TO loome;
```

### 3.2 Flyway 自动迁移

应用启动时 Flyway 自动执行 `src/main/resources/db/migration/V*.sql`，无需手动建表。

**配置**：
```yaml
spring:
  flyway:
    enabled: true
    locations: classpath:db/migration
    baseline-on-migrate: false  # 全新数据库不需要
```

### 3.3 迁移顺序

V1 → V2 → V3 → ... → V10（按版本号顺序自动执行）

## 4. 配置文件（application.yml）

完整配置说明：

```yaml
server:
  port: 8005                   # HTTP 端口

spring:
  application:
    name: loomej-shell
  
  datasource:
    url: jdbc:postgresql://localhost:5433/loome   # 数据库连接 URL
    username: loome
    password: loome
    hikari:
      maximum-pool-size: 10    # 最大连接池大小
      minimum-idle: 2          # 最小空闲连接
      connection-timeout: 30000
  
  flyway:
    enabled: true
    locations: classpath:db/migration
  
  # MCP 静态配置（可选，用于在 application.yml 中预配置 MCP server）
  # 动态 MCP 通过 API 注册，无需在这里配置
  # ai:
  #   mcp:
  #     client:
  #       stdio:
  #         connections:
  #           filesystem-mcp:
  #             command: npx
  #             args: ["-y", "@modelcontextprotocol/server-filesystem", "/workspace"]
  #       sse:
  #         connections:
  #           remote-mcp:
  #             url: http://mcp-server:8090/sse

mybatis:
  configuration:
    map-underscore-to-camel-case: true   # DB underscore → Java camelCase 自动转换
    default-fetch-size: 100
    default-statement-timeout: 30
  type-aliases-package: io.loomej.shell
  mapper-locations: classpath:mapper/*.xml

logging:
  level:
    io.loomej: DEBUG            # 框架内部日志级别
    org.mybatis: INFO
    root: INFO

# LoomeJ 专有配置
loomej:
  llm:
    base-url: https://dashscope.aliyuncs.com/compatible-mode/v1  # OpenAI 兼容 API 地址
    api-key: ${LOOMEJ_LLM_API_KEY:sk-placeholder}                 # LLM API Key
    model: qwen-max                                                # 默认模型
  
  builtin-tools:
    enabled: true              # 是否启用内置工具（bash_exec, read_file 等）
  
  skills:
    dir: ${LOOMEJ_SKILLS_DIR:skills}  # 本地技能目录路径
```

## 5. 环境变量

| 变量名 | 默认值 | 说明 |
|--------|--------|------|
| `LOOMEJ_LLM_API_KEY` | `sk-placeholder` | LLM API Key（必须设置）|
| `LOOMEJ_SKILLS_DIR` | `skills` | 本地技能目录绝对路径 |
| `SPRING_DATASOURCE_URL` | （见 yml） | 数据库 URL（Docker 部署时覆盖）|
| `SPRING_DATASOURCE_USERNAME` | `loome` | 数据库用户名 |
| `SPRING_DATASOURCE_PASSWORD` | `loome` | 数据库密码 |
| `SERVER_PORT` | `8005` | HTTP 服务端口 |

## 6. 启动方式

### 6.1 直接运行（开发）

```bash
# 从 loomej-shell 目录启动（本地技能目录 ./skills）
cd loomej-shell
LOOMEJ_LLM_API_KEY=sk-xxx mvn spring-boot:run

# 或用 fat jar
LOOMEJ_LLM_API_KEY=sk-xxx java -jar target/loomej-shell-*.jar
```

### 6.2 Docker Compose（推荐）

项目根目录提供 `docker-compose.yml`：

```yaml
version: '3.8'
services:
  postgres:
    image: postgres:16
    environment:
      POSTGRES_DB: loome
      POSTGRES_USER: loome
      POSTGRES_PASSWORD: loome
    ports:
      - "5433:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data
  
  loomej-shell:
    build:
      context: .
      dockerfile: Dockerfile
    ports:
      - "8005:8005"
    environment:
      SPRING_DATASOURCE_URL: jdbc:postgresql://postgres:5432/loome
      SPRING_DATASOURCE_USERNAME: loome
      SPRING_DATASOURCE_PASSWORD: loome
      LOOMEJ_LLM_API_KEY: ${LOOMEJ_LLM_API_KEY}
      LOOMEJ_SKILLS_DIR: /app/skills
    depends_on:
      - postgres
    volumes:
      - ./skills:/app/skills  # 挂载本地技能目录

volumes:
  postgres_data:
```

```bash
# 启动
LOOMEJ_LLM_API_KEY=sk-xxx docker-compose up -d

# 查看日志
docker-compose logs -f loomej-shell

# 停止
docker-compose down
```

### 6.3 Dockerfile

```dockerfile
FROM eclipse-temurin:21-jre
WORKDIR /app
COPY loomej-shell/target/loomej-shell-*.jar app.jar
COPY skills/ skills/
EXPOSE 8005
ENTRYPOINT ["java", "-jar", "app.jar"]
```

## 7. 本地技能目录结构

`loomej.skills.dir` 指向的目录结构：

```
skills/
├── python_dev/                  # 技能名
│   ├── skill.md                 # 技能定义（必需）
│   │   ├── ---（YAML frontmatter）
│   │   │   name: python_dev
│   │   │   description: "Python development expert"
│   │   │   version: "1.0.0"
│   │   │   triggers: ["python", "script"]
│   │   └── ---
│   │   # 以下为技能 body（系统提示，注入 LLM system prompt）
│   │   You are an expert Python developer...
│   │
│   ├── scripts/                 # 脚本（可选）
│   │   └── setup_env.sh
│   └── resources/               # 资源文件（可选）
│       └── template.py
│
└── code_review/
    └── skill.md
```

`skill.md` frontmatter 字段：
- `name`：技能唯一标识（必需，与目录名一致）
- `description`：技能描述（显示在 available skills 列表）
- `version`：版本号
- `triggers`：触发关键词列表（语义检索用）

## 8. LLM 账号管理

系统支持多 LLM 账号，通过 `llm_accounts` 表管理。

**插入 LLM 账号（SQL）**：
```sql
INSERT INTO llm_accounts(account_name, base_url, api_key, default_model, enabled)
VALUES 
  ('openai_gpt4', 'https://api.openai.com/v1', 'sk-xxx', 'gpt-4o', true),
  ('qwen_max', 'https://dashscope.aliyuncs.com/compatible-mode/v1', 'sk-yyy', 'qwen-max', true);
```

创建 Session 时通过 `llmAccount` 字段指定账号，运行时 `DatabaseLLMClientResolver` 解析对应配置。

## 10. 远程 Skill Source 配置

### 10.1 远程 skill MCP server 协议要求

服务端必须实现 5 个 MCP 工具（名称可在注册时配置）：

| 工具 | 入参 | 出参格式 | 说明 |
|------|------|---------|------|
| `listSkills` | `{}` | JSON Array: `[{"name":"...", "description":"...", "version":"..."}]` | 列出可用技能 |
| `loadSkillMd` | `{"skillName": "xxx"}` | Markdown 文本字符串 | 加载技能 body |
| `getSkillFiles` | `{"skillName": "xxx"}` | 换行分隔的文件路径 | 列出技能文件 |
| `loadSkillReference` | `{"skillName": "xxx", "referencePath": "..."}` | 文件内容文本 | 加载资源文件 |
| `execSkillScript` | `{"skillName": "xxx", "scriptPath": "..."}` | 脚本输出文本 | 执行脚本 |

所有工具通过 `_meta` 获取调用上下文：
```json
{
  "_meta": {
    "netcowork/sessionId": "sess_xxx",
    "netcowork/agentId":   "agent_xxx",
    "netcowork/taskId":    "task_xxx"
  }
}
```

### 10.2 通过 API 注册

```bash
# STDIO 模式
curl -X POST http://localhost:8005/api/v1/skill-sources/stdio \
  -H "Content-Type: application/json" \
  -d '{
    "sourceName": "my-remote-skills",
    "mcpCommand": "python",
    "mcpArgs": ["/path/to/skill_server.py"]
  }'
```

## 13. 常见问题

**Q: 启动报 "skills dir not found"**  
A: 设置 `LOOMEJ_SKILLS_DIR` 为绝对路径，或在 `loomej-shell/` 目录下创建 `skills/` 目录

**Q: LLM 调用 401 错误**  
A: 检查 `LOOMEJ_LLM_API_KEY` 是否正确设置，以及 `loomej.llm.base-url` 是否与 API key 匹配

**Q: MCP 工具不显示**  
A: 确认 MCP server 已启动，通过 `GET /api/v1/mcp/servers` 确认状态为 CONNECTED

**Q: Session 卡在 INTERRUPTED**  
A: 检查是否有未完成的虚拟线程，通过 `POST /{id}/resume` 恢复

**Q: 远程 skill 返回 "未找到对应的任务"**  
A: 检查 MCP server 是否正确读取 `_meta` 中的 `netcowork/taskId`，以及任务 ID 是否存在于 server 侧的存储中
